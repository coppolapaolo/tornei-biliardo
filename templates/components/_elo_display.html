{# Macro dual-ELO: mostra un valore ELO cliccabile che alterna competitivo <-> globale. Lo swap è gestito da window.EloToggle (base.html), che applica a TUTTI gli `.elo-value` la modalità salvata in localStorage. Il toggle cambia SOLO il numero mostrato: categoria/handicap/seeding e l'ordinamento delle classifiche restano sempre sul valore competitivo. Parametri: competitive - int, ELO competitivo (solo tornei). Default 1200 se None. global_value - int, ELO globale (tornei + casual). Default = competitive. show_label - bool, mostra un'etichetta testuale della modalità attiva. #} {% macro elo_display(competitive, global_value, show_label=false) %} {%- set comp = competitive if competitive is not none else 1200 -%} {%- set glob = global_value if global_value is not none else comp -%} {{ comp }}{% if show_label %} {% endif %} {% endmacro %}
